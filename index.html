💡 iOS PWA 黒帯の根本原因:

WebKitの既知のバグにより、iOSのPWA（ホーム画面に追加）では 100dvh がセーフエリアを含まない高さとして解決されます。

解決策:
#app { height: calc(100dvh + env(safe-area-inset-bottom)); }

これで#appが画面最下端まで到達し、黒帯が消えます。

確認方法:
・赤黄ストライプが見えない → 黒帯なし（OK）
・緑線が画面最下端に到達 → #appが全画面（OK）
・パターンD（100dvhのみ）で黒帯が出ることを確認 → 原因確認
